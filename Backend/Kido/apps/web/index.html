What each sponsor actually does

ENSv2LIVEThe agent's identity and its revocation. The executor reads live registry state at execution time, so revoking a role kills an already-signed, unexpired capability.
Chainlink CRESIMULATORA confidential handlerInTee workflow decides ALLOW/ESCALATE/DENY using private thresholds. Verified in the official CLI simulator against real Sepolia events. Not a live deployment and not a real enclave.
LedgerPENDINGKey Ring keeps a broker credential away from the agent; DMK gates high-risk actions behind a human. Software complete and tested; no physical device was available (BLK-002).
